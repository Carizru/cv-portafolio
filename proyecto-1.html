Descripción del Proyecto

Este proyecto se desarrolló como Trabajo de Fin de Grado en DAW. Es una plataforma integral diseñada para resolver la gestión centralizada de datos y usuarios con seguridad y escalabilidad.

Características Principales

  • Sistema de autenticación y roles de usuario.
  • Panel de administración para control de datos en tiempo real.
  • Base de datos optimizada en MySQL.
  • Interfaz adaptable a dispositivos móviles.

Tecnologías Utilizadas

HTML5 & CSS3 JavaScript (ES6+) PHP MySQL Git
